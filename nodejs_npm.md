# NODEJS > NPM

## SUMMARY
> [!summary]
> Default [[concepts_package_manager|package manager]] for [[nodejs|Node.js]] and also one of the most widely used software registries in the world.

## THEORY

The three main parts of npm are:

1. The [website](https://www.npmjs.com):
	- Search packages
	- Read DOCS
	- Manage organizations or private packages
2. The [[concepts_cli|CLI]]:
	- Automaticly installed with Node.js, and needs it to work.
	- Downloading packages, dependencies, managing package.json, versioning, scripts, publishing...
3. the registry:
	- The database of packages
